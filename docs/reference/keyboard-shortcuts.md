These are the keyboard shortcuts in Relay. Press **?** anywhere outside a
text field to see them in the app. Shortcuts marked *terminal* can be
switched between the Mac, Windows/Linux and Off profiles in **Settings →
Terminal → Shortcuts**.

:::tip
Browsers reserve some shortcuts, such as ⌘T, ⌘W and ⌘N. Relay never
overrides them. [Install Relay as an app](../getting-started/first-steps.md#add-relay-to-your-home-screen)
to free up more of them.
:::

## Everywhere

| Action | Mac | Windows / Linux |
| --- | --- | --- |
| Open the command center | ⌘K | Ctrl+K |
| Show all shortcuts | ? | ? |
| Close a dialog, sheet or menu | Esc | Esc |
| Go to Home | G then H | G then H |
| Go to Terminal | G then T | G then T |
| Go to Agents | G then A | G then A |
| Go to Files | G then F | G then F |
| Go to Code | G then C | G then C |
| Go to Desktop | G then D | G then D |
| Go to Previews | G then P | G then P |
| Go to System | G then S | G then S |
| Go to Settings | G then , | G then , |

The **G then letter** shortcuts work when no text field or terminal has
focus.

## Terminal: editing (*terminal*)

These send the sequences that shells and agent programs understand.

| Action | Mac | Windows / Linux | Sends |
| --- | --- | --- | --- |
| Delete to start of line | ⌘⌫ | Ctrl+Shift+⌫ | Ctrl+U |
| Delete previous word | ⌥⌫ | Ctrl+⌫ | Ctrl+W |
| Delete to end of line | ⌘⌦ or fn⌘⌫ | Ctrl+Shift+Del | Ctrl+K |
| Delete next word | ⌥⌦ | Ctrl+Del | Esc d |
| Start of line | ⌘← | Home | Ctrl+A |
| End of line | ⌘→ | End | Ctrl+E |
| Previous word | ⌥← | Ctrl+← | Esc b |
| Next word | ⌥→ | Ctrl+→ | Esc f |
| New line in an agent prompt | ⇧⏎ | ⇧⏎ | Esc Enter (configurable) |
| Interrupt the running program | Ctrl+C (with no selection) | Ctrl+C (with no selection) | Ctrl+C |

## Terminal: app actions

| Action | Mac | Windows / Linux |
| --- | --- | --- |
| Copy selection | ⌘C | Ctrl+Shift+C, or Ctrl+C with a selection |
| Paste (text, images and files) | ⌘V | Ctrl+Shift+V or Ctrl+V |
| Select all | ⌘A | Ctrl+Shift+A |
| Find in scrollback | ⌘F | Ctrl+Shift+F |
| Clear screen and scrollback | ⌘K | Ctrl+Shift+K |
| Bigger font | ⌘+ | Ctrl+= |
| Smaller font | ⌘− | Ctrl+− |
| Reset font size | ⌘0 | Ctrl+0 |
| New terminal | ⌥⌘T | Ctrl+Alt+T |
| Previous / next tab | ⌥⌘← / ⌥⌘→ | Ctrl+Alt+← / Ctrl+Alt+→ |
| Detach from `relay attach` | Ctrl+\\ then d | Ctrl+\\ then d |

Inside the terminal, ⌘K / Ctrl+Shift+K clears the screen. Open the command
center from the header, or press ⌘K / Ctrl+K while focus is outside the
terminal.

## Phone key bar

| Key or gesture | What it does |
| --- | --- |
| **Ctrl** / **Alt**, tapped once | Applies to the next key only |
| **Ctrl** / **Alt**, double-tapped | Locks on until tapped again |
| Long-press a key | Shows alternatives (for example `-` → `_`) |
| Swipe left or right on the bar | Moves the cursor (faster swipes move further) |
| Swipe up or down on the bar | Steps through command history |
| **^C ^D ^Z ^L ^R** | Interrupt, end of input, suspend, redraw, history search |
